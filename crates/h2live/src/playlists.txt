# The launcher's playlists: the same Halo 2 playlists, played on MCC's
# Halo 2 engine through the launcher (h2launch). Their maps are MCC's map
# file names (halo2\h2_maps_win64_dx11), and their games MCC's own
# matchmaking variants, named by file (halo2\hopper_game_variants, without
# .bin). Launcher playlists can't have bots or splitscreen guests, so
# ranked team games wait for even teams.
#
# Each plays the same game types as the game's playlist of the same name
# above, with the MCC variant closest to it. The variants' own score and
# time limits apply (read on the owner's PC with `h2launch --variants`,
# 2026-10-10, and noted after each line); every one used here has teams on
# exactly when its game type is a team game.
